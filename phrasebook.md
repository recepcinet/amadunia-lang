# Amadunia phrasebook

Everything here obeys the rules in [grammar/](grammar/) and uses only words in
[the dictionary](dictionary/dictionary.md). [`check.py`](check.py) tests every
line on this page along with the lessons.

If you have read [Lesson 1](lessons/lesson-01-greetings.md) you can already say
the first section. The rest draws on the whole course — the last word it needs
arrives in [Lesson 25](lessons/lesson-25-doing-and-being.md), so read
the page for what you can use now rather than as a test of what you have
finished.

---

## Hello and goodbye

| | |
|---|---|
| Hi! | Hello! |
| Salam! | Hello — the peaceful one. |
| Ok? | Are you all right? |
| Ya, ok. | Yes, fine. |
| Pagi hao! | Good morning! |
| Aksam hao! | Good evening! |
| Bai! | Goodbye! |
| Mi saufa lai tena. | I'll come again. |

## Meeting someone

| | |
|---|---|
| Nama yu es ke? | What is your name? |
| Nama mi es Sol. | My name is Sol. |
| Yu es kim? | Who are you? |
| Mi es rafiki Luma. | I am Luma's friend. |
| Yu dari nali? | Where are you from? |
| Mi dari negara baid. | I am from a far country. |
| Mi baru in madina ini. | I am new in this city. |
| Mi studi Amadunia. | I am learning Amadunia. |
| Mi no faham. Sema tena, plis. | I don't understand. Say it again, please. |
| Yu sema hao! | You speak well! |

## Please, thank you, sorry

| | |
|---|---|
| Plis. | Please. |
| Mersi! | Thank you! |
| Pardon! | Sorry. / Excuse me. |
| Ok. No es problema. | Ok. There's no problem. |
| Yu hao! | You are good! |

## Asking the way

| | |
|---|---|
| Pardon! Yu punya tempo? | Excuse me! Do you have a moment? |
| Hotel nali? | Where is the hotel? |
| Market nali? | Where is the market? |
| Anda tarik ini. | Walk this road. |
| Go yamin. | Go right. |
| Go kiri. | Go left. |
| Situ, dekat ponte. | There, near the bridge. |
| Tarik cang o duan? | Is the road long or short? |
| Berapa hora? | How many hours? |
| Mi anda o mi go in tren? | Do I walk or go by train? |

## Buying

| | |
|---|---|
| Berapa harga? | How much? |
| Harga kabir! | That's expensive! |
| Mi mau kupi ini. | I want to buy this. |
| Mi mau ini, no itu. | I want this, not that. |
| Es kamisa lebi keci? | Is there a smaller shirt? |
| Mi punya des pesa. | I have ten pesa. |
| Ok, mi kupi. | Ok, I'll buy it. |
| Mersi! Yu hao. | Thank you! You are good. |

## Eating and drinking

| | |
|---|---|
| Mi mau kula. | I want to eat. |
| Es restoran sini? | Is there a restaurant here? |
| Corba, plis. | Soup, please. |
| Mi mau ca garam. | I want hot tea. |
| Akua barid, plis. | Cold water, please. |
| Ini hao! | This is good! |
| Mi no mau lebi, mersi. | I don't want more, thank you. |
| Bas, mersi. | That's enough, thanks. |

## Time

| | |
|---|---|
| Sasa. | Now. |
| Din ini. | Today. |
| Rat ini. | Tonight. |
| Besok. | Tomorrow. |
| Kemarin. | Yesterday. |
| Mi lai kab? | When shall I come? |
| Mi lai in pagi. | I'll come in the morning. |
| Mi no punya tempo. | I have no time. |

## If something is wrong

| | |
|---|---|
| Madad! | Help! |
| Mi bimar. | I am sick. |
| Sar mi garam. | My head hurts. |
| Mi mau doktor. | I want a doctor. |
| Hospital nali? | Where is the hospital? |
| Mi suda unut anahtar mi. | I have forgotten my key. |
| Mi no naiti dom mi. | I can't find my house. |
| Es bahaya? | Is it dangerous? |
| Polisi nali? | Where are the police? |

## Small talk

| | |
|---|---|
| Din ini hao. | It's a good day. |
| Yamur lai. | It's raining. |
| Angin barid. | The wind is cold. |
| Asman asul. | The sky is blue. |
| Madina ini sundar. | This city is beautiful. |

| Mi punya du anak. | I have two children. |

## Twenty words that will get you a long way

*hi · salam · plis · mersi · pardon · ya · no · ok · bas · madad ·
mi · yu · es · mau · go · lai · nali · berapa · harga · bai*

With these and a pointing finger you can cross a city.

## What this page could not say

A phrasebook is a hard test, because it is made of the things people actually
say rather than the things a grammar has got round to. Four gaps showed up
immediately:

- **No word for "very".** *Thank you very much* and *this is very good* both had
  to lose the "very". *cok* means "much" and whether it can carry "very" is
  [undecided](grammar/adverbs.md).
- **Almost every line is a fragment.** *Sasa.* *Besok.* *Corba, plis.* *Madad!*
  That is what a phrasebook is, and [nothing in the grammar covers it](grammar/questions.md).
- **Half the directions are commands** — *Anda tarik ini*, *Go yamin* — and the
  [imperative was never granted](grammar/questions.md) either.
- **The clock cannot be asked.** *Berapa hora* is "how many hours", not "what
  time"; the language has no word for a clock or an hour of the day.

Nothing was invented to paper over any of them. Four checks in
[`check.py`](check.py) also caught four copula slips in the first draft of this
page — *es* in front of an adjective, the same mistake the lessons made
thirteen times.
