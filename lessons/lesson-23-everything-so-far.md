# Lesson 23 — Everything so far

*Prerequisite: [Lesson 22](lesson-22-doing-and-feeling.md).*

## No new words

This lesson adds nothing. It is the whole of Amadunia on one page, at the point where the dictionary reached three hundred roots and A1 was complete.

## The one sentence

Every rule the language has is in this sentence:

> **Mi no suda kara hao libro ini in dom rat ini porke mi sedih.**
> *I did not read this book well at home last night because I was sad.*

Read it piece by piece:

| Piece | What it does | Rule |
|---|---|---|
| **Mi** | subject | comes first |
| **no** | denies what follows | before the predicate |
| **suda** | past | after *no*, before the verb |
| **kara** | verb | never changes shape |
| **hao** | adverb | adjective straight after the verb |
| **libro** | object | after the adverb |
| **ini** | this | last in the noun phrase |
| **in dom** | place | preposition before the noun |
| **rat ini** | time | place first, then time |
| **porke mi sedih** | reason | the joined clause comes last |

**subject → no → suda/saufa → verb → adverb → object → place → time → clause**

Nothing in that sentence changed its form. Not one word.

## The whole grammar, in twelve lines

| | |
|---|---|
| **Word order** | subject, verb, object |
| **Adjectives** | after the noun — *dom kabir* |
| **Possession** | owner after the thing — *dom mi*; owner before adjective — *dom mi kabir* |
| **This, that** | last in the phrase — *dom mi kabir ini* |
| **Plural** | say the noun twice — *anak-anak*; single after a number — *tri anak* |
| **Tense** | *suda* past, *saufa* future, present unmarked — before the verb |
| **Copula** | *es* before a noun; nothing before an adjective or place |
| **There is** | *es* at the front, no subject — *Es hotel in madina* |
| **Negation** | *no* before the predicate — *Mi no suda kula* |
| **Questions** | rising tone; the question word stays where the answer goes |
| **Verb chains** | verbs simply follow — *Mi mau kula pan* |
| **Comparison** | *lebi/kurang/paling* before the adjective, *dari* for than |

Add *aur* and *o* for joining, *in/dari/por* for place, *una* for with, *porke/kab/agar* for because, when and if — and that is the entire language.

## What has never happened

In three hundred roots and twenty-three lessons:

- **No word has ever changed shape.** No conjugation, no case, no agreement, no plural ending, no gender.
- **No rule has an exception.** Every one of the twelve above holds everywhere, without a list of irregulars.
- **No letter is silent** and no letter has two readings.

## What the language still cannot do

Being honest about this is part of the design:

| Missing | What it blocks |
|---|---|
| A mark for a name | *Sol genc* is "Sol is young" **and** "the sun is young" |
| *never* | only *no daima* and *no saufa*, which are weaker |
| *all, some, none* | quantity beyond *cok* and *lebi* |
| ordinal numbers | *first*, *second* |
| *very* | *cok* is "much"; whether it covers "very" is untested |
| reflexive | *Mi kan mi* reads as "I see me", not clearly "myself" |
| *although, before, after, until* | the second tier of joiners |

Each is recorded as an open question in [grammar/](../grammar/). None was invented to make a lesson easier.

## Where the language stands

Twenty-three lessons, and **256 roots** of the three hundred — Lessons 24 and 25
have the rest. Every root in the dictionary carries a sourced etymology, drawn from Austronesian, Semitic, Latin and Romance, Indo-Aryan, Iranian, Turkic, Niger-Congo, Slavic, Sino-Tibetan, Japonic, Greek and Germanic. No two words differ by a single sound unless that contrast is safe in nearly every language on Earth. No *l* against *r* anywhere.

Twenty letters. One sound each.

*Mi ama dunia. Yu ama dunia. Kita ama dunia.*
