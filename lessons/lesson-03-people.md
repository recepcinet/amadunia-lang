# Lesson 3 — People, day and night

*Prerequisite: [Lesson 2](lesson-02-food-and-home.md).*

## New words

| Word | Meaning |
|---|---|
| anak | child |
| rafiki | friend |
| din | day |
| rat | night |
| kan | to see |
| sema | to say, to speak |
| bil | to know |
| nomu | to drink |
| kabir | big |
| keci | small |
| mal | bad |
| doktor | doctor |

## Talking about people

The sentence shape has not changed since Lesson 2 — subject, verb, object.

| Amadunia | English |
|---|---|
| Mi kan rafiki. | I see a friend. |
| Anak nomu akua. | The child drinks water. |
| Ta bil nama. | She knows the name. |
| Rafiki sema. | The friend speaks. |

## Describing

A quality word follows what it describes:

| Amadunia | English |
|---|---|
| Dom kabir. | The house is big. |
| Anak keci. | The child is small. |
| Ca hao. | The tea is good. |
| Rat mal. | The night is bad. |

There is no separate word for *is*. *Dom kabir* is complete as it stands.

## Day and night

> — Din hao?
> — Ya, din hao. Sol kabir!

> — Rat hao?
> — No. Rat mal.

## Asking for help

> — Salam! Mi mau doktor.
> — Ok. Doktor lai.

## Practice

1. Mi kan anak. — *I see a child.*
2. Rafiki nomu ca. — *The friend drinks tea.*
3. Doktor bil. — *The doctor knows.*
4. Dom mi keci. — *My house is small.*
5. Din kabir, rat keci. — *The day is long, the night is short.*

## What is still open
