# Adverbs — how something is done

*Taught in [Lesson 12](../lessons/lesson-12-colors-directions.md), and extended in [Lesson 18](../lessons/lesson-18-comparing-and-joining.md) for the case where the verb has an object.*

*Status: settled — decided September 3, 2026.*

## The rule

**An adjective placed straight after the verb describes the verb.**

| | |
|---|---|
| Ta anda **hayai**. | She walks fast. |
| Mi kara **hao**. | I read well. |
| Anak kimbia **kuat**. | The child runs strongly. |
| Kita rabota **cok**. | We work a lot. |

No new word, no ending, no separate class of adverbs. The adjective does both jobs, and its position says which one.

This is what the language has been doing since Lesson 12 — *Ta anda hayai* — without ever stating the rule. It is stated now.

## Before the object

When there is an object, the adverb stays with its verb:

| | |
|---|---|
| Mi kara **hao** libro ini. | I read this book well. |
| Ta beri **hayai** ca por mi. | She quickly gives me tea. |

Keeping the adverb against the verb is what makes it unambiguous. Put it after the object and it would attach to the object instead: *Mi kara libro hao* is "I read a good book".

| | |
|---|---|
| Mi kara **hao** libro. | I read a book well. |
| Mi kara libro **hao**. | I read a good book. |

The word never changes; only its place does.

## The full order

Everything the language has settled, in one line:

> **subject → no → suda/saufa → verb → adverb → object → place → time → clause**

| | |
|---|---|
| Mi no suda kara hao libro ini in dom rat ini porke mi sedih. | I did not read this book well at home last night because I was sad. |

Every rule in Amadunia is in that sentence, and not one word in it has changed its shape.

## Sources

Using one form for adjective and adverb is the majority pattern: Chinese, Indonesian, Malay, Turkish (*hızlı* both ways), German (*schnell* both ways), Swahili, Japanese in part. English *-ly* and Romance *-mente* are the minority, and both come with irregulars — English *good/well*, *fast/fast*, *hard/hardly*.

## Open questions

- **Adverbs of degree on adverbs** — "very quickly" — needs a word for "very". *cok* is "much"; whether it covers "very" is untested.
- **Whether *daima* covers "forever".** It is glossed "always", from Arabic *dāʾiman*, which carries both senses. *Natura hidup daima* would say nature lives forever, and *Mi kula daima pan* says I always eat bread — habit and endlessness in one word and one slot. Most languages separate them. This is the same shape of question as *cok* and "very" above, and it was found the same way: [text 10](../texts/text-10-mila-tahun.md) recorded that the language had no word for *forever* without checking what it did have.
- **Frequency adverbs.** *daima* (always) and *kadang* (sometimes) are adverbs by meaning but not adjectives. This page used to say they sit in the adverb slot with everything else; **counted on September 4, 2026, two of their thirteen uses do.** Five stand before the verb and six after the object, and Lesson 19 alone uses all three positions. [A briefing measures it and costs the three answers](proposal-frequency.md). Until it is decided the word *kadang* cannot be written at all, because any sentence using it would settle the question by accident.
