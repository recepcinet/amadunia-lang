# Writing

How Amadunia is written down and passed between people — as opposed to how it is
built, which is [grammar/](../grammar/).

Nothing in this folder changes the language. A speaker who never reads it can still
write and say everything; these are conventions for when the plain letters are not
enough on their own — a bad phone line, a keyboard you type on all day.

- [keyboard.md](keyboard.md) — an optional layout, and why none is required
- [spelling-alphabet.md](spelling-alphabet.md) — words for spelling a word aloud

Both are marked *proposed*: they are drafts for the founder, not settled decisions.
